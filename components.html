Internal Components

Motherboard

Description: The large circuit board that connects the computer's major components.

Function: Allows the CPU, RAM, storage, expansion cards, and peripherals to communicate.

Basic specifications: ATX, Micro-ATX, or Mini-ITX form factor; CPU socket; RAM slots; expansion slots; USB and display ports.

Central Processing Unit (CPU)

Description: A small processor installed in a socket on the motherboard.

Function: Reads and executes instructions, performs calculations, and manages computer operations.

Basic specifications: Core count, thread count, clock speed, cache size, socket, and thermal design power.

Random Access Memory (RAM)

Description: Temporary memory modules installed in the motherboard's memory slots.

Function: Holds data and programs that are actively being used by the CPU.

Basic specifications: Capacity in GB, DDR generation, speed in MHz, latency, and number of modules.

Power Supply Unit (PSU)

Description: The component that receives power from an outlet and supplies it to the computer.

Function: Converts AC electricity into regulated DC electricity for the internal components.

Basic specifications: Wattage, 80 PLUS efficiency rating, modular or non-modular cables, connectors, and form factor.

Input Devices

Keyboard

Description: A board with keys used to enter text, numbers, symbols, and commands.

Function: Sends typed characters and key commands to the computer.

Basic specifications: Layout, key count, connection type, switch type, and presence of a numeric keypad.

Mouse

Description: A hand-held pointing device with buttons and a movement sensor.

Function: Controls the pointer and lets the user click, select, drag, and scroll.

Basic specifications: DPI range, sensor type, number of buttons, polling rate, and wired or wireless connection.

Microphone

Description: An audio input device that captures a person's voice or other sounds.

Function: Changes sound waves into an audio signal for recording, calls, or broadcasts.

Basic specifications: Connection type, pickup pattern, frequency response, sensitivity, and sample rate.

Output Devices

Monitor

Description: An electronic display that shows the computer's visual output.

Function: Presents text, images, video, and software interfaces to the user.

Basic specifications: Screen size, resolution, refresh rate, panel type, brightness, and video ports.

Speakers

Description: Audio output devices that use a driver to produce sound.

Function: Play music, voices, alerts, and other sounds from the computer.

Basic specifications: Number of channels, power output, frequency response, connection type, and volume controls.

Printer

Description: A device that puts digital documents or images onto paper.

Function: Produces physical copies of computer output.

Basic specifications: Inkjet or laser technology, print speed, print resolution, paper sizes, and color support.

Storage Devices

Hard Disk Drive (HDD)

Description: A storage device that uses spinning magnetic platters and a moving read/write head.

Function: Stores the operating system, applications, and files for long-term use.

Basic specifications: Capacity, rotation speed in RPM, cache, SATA interface, and 2.5-inch or 3.5-inch form factor.

Solid-State Drive (SSD)

Description: A storage device that uses flash memory instead of spinning disks.

Function: Saves files and programs and provides faster access than many traditional hard drives.

Basic specifications: Capacity, sequential read and write speed, SATA or NVMe interface, form factor, and endurance.

USB Flash Drive

Description: A small portable device that stores data using flash memory.

Function: Transfers, stores, and backs up files between compatible devices.

Basic specifications: Capacity, USB-A or USB-C connector, USB version, read speed, and write speed.
