Lesson 1: Internal Components

Internal components are the parts inside the computer case. They work together to process instructions, provide power, and connect the other hardware.

Motherboard

The motherboard is the main circuit board of a computer. It provides connections for the processor, memory, storage, expansion cards, and other devices.

Basic specifications to check: Form factor, processor socket, RAM slots, expansion slots, and supported ports.

Central Processing Unit (CPU)

The CPU executes instructions and performs calculations. It is often called the brain of the computer because it controls many of the computer's operations.

Basic specifications to check: Number of cores, clock speed in GHz, socket type, cache size, and power rating.

Random Access Memory (RAM)

RAM temporarily holds the programs and data that the CPU is currently using. More RAM can help a computer handle more applications at the same time.

Basic specifications to check: Capacity in GB, memory type, speed in MHz, and number of modules.

Power Supply Unit (PSU)

The PSU changes electricity from the wall outlet into the lower-voltage power used by the computer's components.

Basic specifications to check: Wattage, efficiency rating, connector types, and form factor.

Lesson 2: Input Devices

Input devices allow a user to send commands, text, images, and other information to a computer.

Keyboard

A keyboard is used to type letters, numbers, symbols, and shortcuts. It can also include special keys for controlling media and other functions.

Basic specifications to check: Connection type, keyboard layout, number of keys, and switch type.

Lesson 4: Storage Devices

Storage devices keep files, programs, and the operating system so that information remains available after the computer is turned off.

Hard Disk Drive (HDD)

An HDD stores data on rotating magnetic disks. It can provide a large amount of storage at a lower cost.

Basic specifications to check: Capacity in TB, rotation speed in RPM, cache, interface, and form factor.

Solid-State Drive (SSD)

An SSD stores data on flash memory and has no moving disks. It usually starts programs faster and is quieter than an HDD.

Basic specifications to check: Capacity, read and write speed, interface, form factor, and endurance rating.

A USB flash drive is a small, portable storage device used to transfer or back up files between compatible computers.

Basic specifications to check: Capacity, USB version, transfer speed, and physical connector.

Lesson Review

  1. Internal components process information and make the computer work.
  2. Input devices send information from the user to the computer.
  3. Output devices show or play the results produced by the computer.
  4. Storage devices keep files and programs for later use.
