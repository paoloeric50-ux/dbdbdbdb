About EduXplore

EduXplore is an interactive web-based learning guide about basic computer hardware. It helps students identify computer parts and understand their descriptions, functions, and basic specifications using only a web browser.

Project Purpose

The purpose of EduXplore is to make learning computer hardware simple, organized, and engaging. Students can browse lessons, view computer components, search for specific parts, and answer short multiple-choice quizzes to review what they learned.

Target Users

EduXplore is designed for the following users:

  • Junior high school students
  • Senior high school students
  • ICT students
  • Beginners who want to learn computer hardware
  • Teachers who need supplementary learning material

Main Features

  • Categorized computer hardware lessons
  • Pictures and labeled diagrams of computer parts
  • Names, descriptions, functions, and basic specifications
  • Search feature for computer components
  • Short multiple-choice quizzes with scores and feedback
